# 🎨 Color Palette Generator

A simple and responsive Color Palette Generator built using **HTML**, **CSS**, and **JavaScript**. The application generates five random hexadecimal colors and allows users to copy any color code with a single click.

## Features

* Generate five random colors instantly
* Display hexadecimal color codes
* Copy color codes by clicking the copy icon
* Copy color codes by clicking the color box
* Visual success indicator after copying
* Responsive layout for desktop and mobile devices

## How to Use

1. Open the project in your browser.
2. Click the **Generate Palette** button.
3. A new set of five random colors will be displayed.
4. Click a color box or the copy icon to copy its hexadecimal color code.
5. Paste the copied color anywhere you need it.
